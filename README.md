# Student Services Portal

## 📝 Project Description

A TypeScript-based web application for managing university student services. This project demonstrates professional development practices including TypeScript, Git workflow, and AI-assisted development.

## 📋 Requirements

- Node.js (v18 or higher)
- npm (v8 or higher)
- Git
- TypeScript
